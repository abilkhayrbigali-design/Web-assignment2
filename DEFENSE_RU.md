# Как защитить Assignment 2

## Что реализовано

Проект содержит восемь связанных страниц Steam Game Hub. Flexbox используется для меню и компонентов, а CSS Grid - для структуры страниц и галереи. Все страницы адаптируются к узким экранам. Галерея находится на странице Community, раздел Art gallery.

## Task 1: меню

Открой `css/part1.css`. `.navbar` - Flexbox-контейнер с логотипом и списком ссылок. `justify-content: space-between` распределяет их к краям главной оси; `align-items: center` центрирует по поперечной оси. При `flex-direction: row` главная ось горизонтальная. `gap` задает промежутки, `flex-wrap` разрешает перенос. Внутренний список ссылок тоже использует Flexbox.

## Task 2: карточки

`.card-row` использует `display: flex`, `flex-wrap: wrap`, `align-items: stretch`, `gap: 24px`. Ширина одной из четырех карточек равна `(100% - 72px) / 4`: между четырьмя карточками три промежутка по 24px. На более узких экранах остаются две или одна карточка в ряду.

Высоты одинаковы в пределах ряда. Внутри карточки применяется `flex-direction: column`; содержимое с `flex: 1` заполняет свободное место, а `margin-top: auto` сдвигает кнопку вниз. Для перехода используется `<a>`, а не `<button>`. `:hover`, `transform`, `box-shadow` и `transition` создают плавный эффект при наведении.

## Task 3: Grid Areas

Открой `css/assignment2.css`. Родительский контейнер - `<body class="site-layout">`.

```css
grid-template-columns: 220px minmax(0, 1fr);
grid-template-rows: auto 1fr auto;
grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
```

Первый столбец имеет ширину 220px, второй занимает оставшееся место. `minmax(0, 1fr)` позволяет основному столбцу сжиматься без переполнения из-за длинного содержимого. `auto` подстраивает строки шапки и подвала под контент. Средняя строка заполняет остаток высоты, поэтому подвал находится внизу даже на короткой странице.

Свойство `grid-area` связывает каждый дочерний элемент с именованной областью. Повторение слова `header` или `footer` в обеих колонках означает, что область занимает всю строку. При ширине до 1200px области располагаются последовательно: header, sidebar, main, footer.

## Task 4: галерея

На Community находятся 9 разных SVG-файлов. Это отдельные изображения, подключенные через `<img>`, а не один фон. Контейнер `.gallery-grid` использует:

```css
grid-template-columns: repeat(3, minmax(0, 1fr));
grid-auto-rows: 1fr;
gap: 20px;
```

Получается три равных столбца и равные строки. Пропорция изображения задается `aspect-ratio: 8 / 5`, а `object-fit: cover` заполняет рамку без искажения пропорций. Подпись находится в `<figcaption>` поверх изображения. При наведении или `:focus-visible` ее `opacity` меняется с 0 на 1. На сенсорных устройствах подпись видна постоянно, поскольку там нет обычного наведения мыши. Нажатие открывает сам файл изображения.

## Part 3: адаптивность и доступность

- `@media` меняет стили при заданной ширине экрана.
- Grid управляет строками и колонками, Flexbox удобен для выравнивания элементов по одной оси.
- `min-width: 0` позволяет Grid/Flex-элементу сжиматься.
- `box-sizing: border-box` включает padding и border в заданную ширину.
- `alt` описывает изображение; `aria-current="page"` отмечает текущую страницу.
- Ссылка Skip to content позволяет перейти к основному содержимому с клавиатуры.
- `:focus-visible` показывает, какой элемент выбран клавишей Tab.
- `prefers-reduced-motion` отключает анимацию при соответствующей настройке пользователя.
- Формы используют встроенную HTML-проверку `required` и `type="email"`. JavaScript показывает локальный результат проверки и предотвращает отправку; серверной части нет.

## Part 4: публикация

Исходники находятся в репозитории `abilkhayrbigali-design/Web-assignment2`. GitHub Pages публикует статические файлы из корня ветки `main`. Начальная страница называется `index.html`; относительные ссылки позволяют сайту работать как локально, так и внутри адреса репозитория. Файл `.nojekyll` позволяет публиковать статические файлы без обработки Jekyll.
